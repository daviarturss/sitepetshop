# PetShop Amigo Feliz

## Sobre o projeto
Eu desenvolvi este site como um modelo fictício de landing page de conversão para um petshop. O objetivo era demonstrar como atrair tutores, gerar leads rápidos e aumentar as vendas de serviços e produtos.

## Funcionalidades principais
* Hero com proposta de valor clara e CTA duplo para WhatsApp e agendamento online
* Formulário de agendamento rápido que abre o WhatsApp com os dados preenchidos automaticamente
* Seções de Serviços, Produtos selecionados, Depoimentos e Contato
* Oferta promocional de combo com escassez
* Botões de WhatsApp espalhados pela página para reduzir atrito
* Design responsivo, leve e otimizado para velocidade

## Tecnologias usadas
HTML5, CSS3 com variáveis, JavaScript vanilla para scroll suave e envio para WhatsApp

## Principais aprendizados
Ao criar este projeto eu aprendi a priorizar a conversão acima do excesso visual. Entendi a importância de um formulário curto, CTAs visíveis e prova social para gerar confiança. Também reforcei boas práticas de acessibilidade e responsividade mobile first.
